# AANID

Application de gestion de la panneautique urbaine.

## Structure

```
ANNID/
├── backend/              # API Gateway central
├── frontend/             # React shell principal
├── shared/               # Types et utils partagés
├── beni-momo-adnan/      # Villes, Relais Pub, Formations
├── bryan-fanou/          # États des lieux
├── rayan/                # Carte Interactive
├── w-d/                  # Authentification & Profil
└── undef/                # Posts/Réseaux, Consultation (chef de projet)
```

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```
