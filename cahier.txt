1. Présentation du projet
1.1 Contexte et vision
Panotic est une plateforme numérique internationale, hybride et collaborative, dédiée à la panneautique
— la conception, l'installation, la maintenance et la gestion des panneaux publicitaires et du mobilier
urbain de publicité. Elle représente une réponse innovante aux défis de modernisation de l'affichage
extérieur en Afrique de l'Ouest et au-delà.
La vision est de faire de Panotic le référent panafricain, puis international, de la panneautique moderne
et responsable, en alliant business, formation, signalement citoyen et impact social.

1.2 Problèmes adressés
•
•
•
•
•

Absence de cartographie fiable du mobilier urbain publicitaire en Afrique de l'Ouest
Manque de formation professionnelle certifiante et accessible dans le secteur de la
panneautique
Déconnexion entre régies publicitaires, annonceurs et espaces disponibles
Absence d'outil citoyen structuré pour signaler les dégradations visuelles et
environnementales
Lenteur de la transition numérique dans l'affichage extérieur

2. Objectifs de l'application
Quatre piliers stratégiques de Panotic
O1 — Information & cartographie en temps réel
Fournir une cartographie interactive actualisée du mobilier urbain de publicité (panneaux classiques,
obsolètes, digitaux, abribus, totems…) permettant aux autorités, professionnels et citoyens de
visualiser l'état du parc publicitaire urbain.

O2 — Formation et professionnalisation
Offrir des formations certifiantes et pratiques accessibles via mobile money, carte bancaire ou tout
moyen de paiement local, couvrant la conception, les normes techniques, l'installation, la maintenance
et la transition vers le digital.

O3 — Relais publicitaire innovant
Mettre en relation directe régies publicitaires et annonceurs avec un inventaire géolocalisé et vérifié du
mobilier urbain disponible, valorisant ainsi les espaces de qualité.

O4 — Impact social & environnemental
Transformer les utilisateurs en acteurs du changement en leur permettant de dénoncer les
dysfonctionnements et de sensibiliser autour de trois thématiques : protection de l'environnement,
cadre de vie sain, et environnement familial convenable.

4. Fonctionnalités détaillées
4.1 Signalement citoyen (Core Feature)
F01 — Module de signalement géolocalisé
Description fonctionnelle
Le module de signalement constitue le cœur fonctionnel de l'application. Il permet à tout utilisateur
enregistré de géolocaliser et de documenter l'état d'un panneau ou d'un élément de mobilier urbain
publicitaire.

Flux utilisateur
1.
2.
3.
4.
5.
6.

L'utilisateur ouvre l'application et se positionne sur la carte
Il sélectionne un panneau existant ou en crée un nouveau sur la carte
Il choisit le type de signalement (état dégradé, obsolète, dangereux, illégal, etc.)
Il ajoute photo(s), vidéo(s) et commentaire(s)
L'application génère un rapport synthétique horodaté et géolocalisé
Le signalement est publié sur la carte communautaire et dans le fil de signalements

Spécifications techniques
•
•
•
•
•
•
•

Géolocalisation GPS native avec précision ≤ 10m
Upload photos : JPEG/PNG, max 10 Mo, compression automatique avant envoi
Upload vidéos : MP4/MOV, max 100 Mo, 30 secondes maximum
Génération PDF du rapport côté serveur
Mode hors-ligne : mise en file d'attente et envoi différé à la reconnexion
Types de statuts : Bon état / Dégradé / Obsolète / Dangereux / Illégal / En travaux
Système de vote communautaire (confirmer / infirmer un signalement)

Note opérationnelle importante
Cette fonctionnalité est pleinement optimale avec des panneaux à affichage digital (lecture temps réel
via géolocalisation). Dans les zones à panneaux classiques (majorité en Afrique de l'Ouest), elle reste
fonctionnelle via signalement manuel. Il est recommandé de nouer des partenariats techniques avec
au moins une ville équipée en panneaux digitaux dès le lancement.

5. Architecture de l'application
5.1 Architecture générale
L'application adopte une architecture mobile-first basée sur React Native avec un backend API REST.
La communication se fait via HTTPS avec authentification JWT et rafraîchissement de token
automatique.

Architecture en couches : Mobile → API Gateway → Services → Base de données
Couches techniques
•
•
•
•
•
•
•

Couche présentation : React Native (iOS + Android), composants réutilisables
Couche logique métier : Redux Toolkit, services React Native
Couche réseau : RTK Query + Axios, gestion de cache et synchronisation offline
API Gateway : NestJS, authentification, rate limiting, logging
Microservices : Signalement, Formation, Publicité, UGC, Notification
Base de données : PostgreSQL + PostGIS pour les données géospatiales
Stockage médias : AWS S3 / Cloudflare R2 + CDN Cloudflare

5.2 Authentification et sécurité
•
•
•
•
•

Inscription : email/mot de passe, numéro de téléphone (SMS OTP), Google/Apple Sign-In
Authentification à deux facteurs (2FA) par mail
Token JWT avec expiration courte (15min) + refresh token longue durée (30 jours)
Chiffrement des données sensibles au repos (AES-256) et en transit (TLS 1.3)
Conformité RGPD et lois locales sur la protection des données personnelles
Modération de contenu : algorithme IA + modérateurs humains

15. Glossaire
Terme

Définition

Panneautique

Secteur d'activité lié à la conception, installation, maintenance et gestion des
panneaux publicitaires et du mobilier urbain de publicité

Mobilier urbain

Ensemble des équipements installés sur la voie publique : abribus, panneaux,
totems, kiosques, colonnes Morris, etc.

UGC

User Generated Content — contenu créé et publié par les utilisateurs de la
plateforme

Régie publicitaire

Entreprise spécialisée dans la commercialisation d'espaces publicitaires

Mobile Money

Service de paiement mobile permettant des transactions financières via
téléphone portable, très répandu en Afrique de l'Ouest

PostGIS

Extension géospatiale de PostgreSQL permettant le stockage et le traitement
de données de localisation

MVP

Minimum Viable Product — version minimale d'une application permettant de
valider les hypothèses fondamentales du produit

React Native

Framework JavaScript open-source développé par Meta permettant de créer
des applications mobiles natives pour iOS et Android depuis un code base
unique

OTP

One-Time Password — code à usage unique envoyé par SMS pour
l'authentification

CDN

Content Delivery Network — réseau de serveurs distribués permettant la
livraison rapide de contenus aux utilisateurs selon leur localisation
géographique
